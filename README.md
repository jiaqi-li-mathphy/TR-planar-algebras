# Triangle Relation Planar Algebras

**Computational code and data accompanying the paper**

*Triangle Relation Planar Algebras: Cohomology, Classification, and New Families*

**Authors:** Jiaqi Li and Zhengwei Liu

## Overview

This repository provides computational materials accompanying our classification of bi-commutative triangle relation (TR) planar algebras with two-box dimension at most five.

The classification combines fusion-support enumeration, cohomological tests, fusion equations, Fourier matching, and consistency equations.

## Code and Computational Data

The computational materials are distributed through the **[GitHub Releases](https://github.com/jiaqi-li-mathphy/TR-planar-algebras/releases)** page.

The materials are organized by computational branch, covering ranks 2, 3, and 4, together with the three rank-five duality types: self-dual, (12), and (12)(34).

Individual releases provide the relevant downloadable archives. Please consult their descriptions to identify the appropriate packages.

## Reproducibility

The computational workflow follows Algorithms 1 and 2 of the paper:

Support enumeration → Cohomological sieve → Fusion equations → Fourier matching → Consistency equations.

For implementation details, software requirements, and instructions for inspecting or reproducing the results, consult the documentation included in the corresponding downloadable archives.
